# Control Center — observed brand spec

- `--bg`: near-black charcoal, used as the main application canvas.
- `--surface`: slightly lifted graphite for panels and cards.
- `--fg`: soft near-white for primary labels and values.
- `--muted`: cool gray-blue for supporting copy and metadata.
- `--border`: low-contrast white hairlines for structure.
- `--accent`: indigo-violet for selected navigation, links, and primary actions.

- Display: Inter Variable / Inter, system fallbacks.
- Body: Inter Variable / Inter, system fallbacks.
- Mono: Berkeley Mono / ui-monospace.

Observed rules:

1. Dark mode is the native medium; depth comes from small luminance steps.
2. Indigo is reserved for active navigation, links, selected states, and one primary action.
3. Tables and operational lists are dense but separated by quiet dividers.
4. Status is communicated through compact pills and small signal dots rather than large color blocks.
5. The shell is left-rail based, with a centered content column and generous empty canvas.
